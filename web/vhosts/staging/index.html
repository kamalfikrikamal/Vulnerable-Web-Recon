Staging Environment

Build saat ini: NusaCMS v2.4.0-beta

Environment ini digunakan tim internal untuk uji coba rilis berikutnya sebelum di-deploy ke production (yang masih menjalankan v2.3.1).

Halaman ini tidak ditautkan dari manapun - kalau kamu sampai di sini, kamu pasti sudah menemukan staging.corplab.local lewat DNS/sertifikat, lalu memetakannya ke /etc/hosts.
